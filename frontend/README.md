# Huellitas AI - Plataforma de Adopción

Sistema integral de adopción canina con modelo predictivo de Machine Learning.

## Tecnologías
- **Frontend:** Next.js (App Router), React, CSS Modules
- **Backend/Base de Datos:** Supabase (PostgreSQL, Auth, Storage)
- **Machine Learning (Próximamente):** Python, FastAPI, Scikit-Learn

## Estructura
- `frontend/`: Contiene el portal web principal.
- `backend/`: (Próximamente) Modelo de recomendación de adopciones.
